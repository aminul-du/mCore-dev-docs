Deployment Workflow

3-part master sync
PART 1
Backup
Read-only snapshot of all 5 repo trees, configs, kernel artifacts, SSH keys → tar.zst + SHA256SUMS
PART 2
5-Repo Sync
git init · identity · remote · README · .gitignore · commit · push to each GitHub repo
PART 3
Verify
HTTP checks on Pages, goGit, /health · systemd unit states · listening ports
FINAL
AIS Approval
Human-in-the-loop acceptance · production promotion blocked until G01–G15 pass

Do NOT

Red lines
❌
Never commit .env, *.pem, id_rsa, known_hosts, or any private key. .gitignore blocks them but verify before push.
❌
Never force-push to main. No git push --force. Preserve history.
❌
Never push to production without AIS-signed change ID. Silent approval is forbidden.
❌
Never assume Green. The backup script produces evidence; only human review declares success.
